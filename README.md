# Учебно-методическое пособие CubeSat

Сборно-разборный макет спутника типа CubeSat: механическая сборка, подключение электроники, программирование датчиков, снятие телеметрии и итоговое испытание.

## Структура репозитория

```
├── Методическое пособие.html   # главная страница (точка входа)
├── assembly/                   # вкладка «Сборка» — чертёж и инструкция
├── code/                       # вкладка «Код» — программы и редактор
├── practice/                   # вкладка «Практика» — лабораторные
├── diag/                       # вкладка «Диагностика» — неисправности и отчёт
├── style.css                   # общие стили
├── app.js                      # общий скрипт (навигация, темы, редактор)
├── Vector.png / Vector2.png    # логотипы (светлая/тёмная тема)
├── files/                      # примеры файлов для панели редактора
└── server.js                   # локальный Node-сервер (для запуска на ПК)
```

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите содержимое этой папки в репозиторий.
3. В настройках репозитория: **Settings → Pages → Branch: main → / (root) → Save**.
4. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.

## Локальный запуск

Просто откройте `Методическое пособие.html` в браузере — сайт статический и работает без сервера.

Для запуска через Node:

```
node server.js
```

Сайт будет доступен на http://localhost:8080.
